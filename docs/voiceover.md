# Voiceover script

This file is the single source for the narration. `npm run voiceover` turns every `>` line below into an MP3 using ElevenLabs. Edit the text here, not in the audio tool.

Rules for the words: short sentences, spoken English, nothing a person would stumble on. About 150 words a minute. The live demo parts keep Pip's real voice and yours, so the narration only frames them.

Total target: under 100 seconds of narration in a video of about 3 minutes.

### 01-hook

*Over the landing page. Starts at 0:00.*

> Every company has a Maria. Fourteen years in accounts payable. The manual says hold the invoice. Maria approves it, because she knows something the manual doesn't. Every rule has a caveat. Her best colleagues know them all. And none of it is written down.

### 02-what

*Over the landing page, ending as you click "Shadow Maria".*

> This is Caveat AI. Pip is an apprentice built on ElevenLabs agents. It sits beside an expert while they work, watches every lookup and decision, and compares them with the written procedure. It only speaks when the expert breaks it.

### 03-map

*Over the Work Map screen, after the live capture.*

> Every answer becomes a rule on a live Work Map. When, then, because, unless, in Maria's own words, linked to the invoice that prompted it, and confirmed by her.

### 04-tutor

*Over the Work Map screen, right after `03-map` and before you click "Teach with Maria's full example map". Pip's own voice starts the moment you click, so this cannot go later.*

> Now a second voice agent teaches a new hire from that map. It never gives the answer first. It asks. It hints. Only then does it reveal the rule, in Maria's words.

### 05-principles

*Over the capture screen with the loop bar visible (Clip D). Start it about 8 seconds in, after Pip's greeting has finished.*

> We built Pip to be trusted next to an expert. It shows why it speaks. It stays quiet when it should. The expert can pause it, skip a question, or discard a rule. And nothing is remembered until the expert confirms it.

### 05b-benchmark

*Optional. Use it only if you really worked all eight invoices on camera.*

> In a full eight-invoice run, Pip surfaced all six hidden rules we had seeded.

### 06-close

*Over the landing page. Ends the video.*

> Caveat AI. Every rule has a caveat. Your best people know them all. Now someone can learn them.
